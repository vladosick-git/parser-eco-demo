# Схема данных

Все файлы лежат в `data/`, кодировка UTF-8. Даты в ISO 8601, время приводится к московскому (`+03:00`). Если источник отдаёт только дату, поле содержит `YYYY-MM-DD`.

| Файл | Что внутри |
|---|---|
| `news.json`, `news.csv` | новости (раздел A) |
| `waste.json`, `waste.csv` | объявления и закупки по отходам (раздел B) |
| `runs.json` | журнал запусков |
| `sources.json` | таблицы из `docs/AUDIT.md` для вкладки «Источники» на витрине |
| `http_cache.json` | ETag и Last-Modified для условных запросов, служебный |
| `bundle.js` | те же данные одним JS-файлом, чтобы витрина открывалась с диска без сервера |

CSV разделены точкой с запятой, в UTF-8 с BOM, чтобы Excel сразу открывал кириллицу.

## Общие поля записи

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | 16 hex-символов, sha1 от `source_id` + канонической ссылки. Ключ дедупликации внутри источника |
| `content_key` | string | sha1 от нормализованного заголовка + даты (без времени). Ловит одну и ту же запись из разных источников |
| `source_id` | string | id адаптера, например `mnr` |
| `source_name` | string | название источника |
| `title` | string | заголовок без HTML, телефонов и e-mail, до 200 символов |
| `published` | string или null | дата публикации |
| `url` | string | ссылка на первоисточник |
| `collected_at` | string | когда запись впервые попала в базу |

## Новость (`news.json`)

| Поле | Тип | Описание |
|---|---|---|
| `summary` | string | краткое описание до 300 символов, может быть пустым |
| `category` | string | одна из: `Законодательство`, `Мероприятия`, `Переработка`, `Отходы и ТКО`, `Экология` |

Автор и полный текст не сохраняются.

## Объявление или закупка (`waste.json`)

| Поле | Тип | Описание |
|---|---|---|
| `offer_type` | string или null | `куплю`, `продам`, `вывоз`, `утилизация` |
| `category` | string | `Пластик`, `Макулатура`, `Металл`, `Стекло`, `Шины и резина`, `Нефтепродукты`, `Жидкие отходы`, `ТКО`, `Опасные отходы`, `Прочее` |
| `fkko` | string или null | код ФККО, ровно 11 цифр без пробелов |
| `hazard_classes` | int[] | классы опасности 1-5. Берутся из текста («I-IV класса») или из последней цифры ФККО |
| `volume`, `volume_unit` | number, string или null | объём в `т`, `м3` или `шт` (кг пересчитываются в тонны) |
| `price`, `currency` | number, string или null | цена числом и код валюты (`RUB`, `USD`, `EUR`). Ноль и «договорная» дают null |
| `region_code`, `region` | string или null | код и название субъекта РФ из справочника `collector/regions.py` |
| `organization` | string или null | только юрлицо или госорган. ИП, логины и всё похожее на ФИО отбрасываются |

Контакты, логины авторов и тексты объявлений не сохраняются.

## Журнал запусков (`runs.json`)

Массив, новые запуски первыми, хранится не больше 200.

```json
{
  "run_id": "2026-10-17T21:00:05+03:00",
  "started_at": "2026-10-17T21:00:05+03:00",
  "finished_at": "2026-10-17T21:04:41+03:00",
  "duration_s": 276.1,
  "status": "ok | partial | failed",
  "totals": {"fetched": 120, "new": 37, "duplicates": 70, "skipped": 13, "errors": 0},
  "sources": [
    {
      "source_id": "mnr",
      "source_name": "Минприроды России",
      "kind": "news",
      "status": "ok | not_modified | error",
      "fetched": 4, "new": 1, "duplicates": 3, "skipped": 0, "errors": 0,
      "error": null,
      "duration_s": 0.8
    }
  ]
}
```

`fetched` - сколько записей разобрано из ответов, `new` - сколько добавлено, `duplicates` - сколько отброшено дедупликацией, `skipped` - без заголовка или ссылки либо новости старше 180 дней. `fetched = new + duplicates + skipped`. `not_modified` означает, что сервер ответил 304 на условный запрос.
