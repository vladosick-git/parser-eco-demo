# Аудит источников

Дата проверки всех источников: **2026-10-17**. Проверка вручную: `robots.txt`, наличие RSS или списка, заголовки кэширования (ETag, Last-Modified), условия использования в подвале сайта или в пользовательском соглашении, наличие персональных данных в выдаче.

User-Agent при проверке: `EcoCollectorDemo/0.1`. Между запросами к одному домену пауза не меньше 2 секунд.

## Что сохраняем из любого источника

Только заголовок, описание до 300 символов, дату, категорию, регион, цену и ссылку на первоисточник. Полные тексты, фото, контакты, имена пользователей и телефоны не сохраняются.

### Про ФККО и класс опасности

Ни в одном из разрешённых источников код ФККО отдельным полем не публикуется. Нормализация ФККО к 11 цифрам будет реализована и покрыта тестами, но в реальных данных поле почти всегда будет пустым. Класс опасности иногда встречается в названиях закупок («отходов I-IV класса опасности»), его будем извлекать оттуда.

## Технические риски, найденные при проверке

1. **Сертификаты.** У mnr.gov.ru, zakupki.gov.ru и torgi.gov.ru сертификат выдан российским удостоверяющим центром (Russian Trusted Root CA Минцифры). Стандартные хранилища сертификатов его не знают: `curl` на Windows и внешний сервис загрузки страниц выдали ошибку доверия. Решение без обхода защиты: положить публичный корневой сертификат Минцифры в репозиторий и передавать его в HTTP-клиент вместе со стандартным набором `certifi`. Отключать проверку TLS не будем.
2. **GitHub Actions за рубежом.** Проверено 2026-10-17 первым запуском workflow: с раннеров GitHub mnr.gov.ru и zakupki.gov.ru не принимают соединение (`ConnectTimeout`), остальные 5 источников работают. Сбой виден в журнале, остальные источники собираются. Чтобы собирать и госисточники по расписанию, нужен запуск из РФ: self-hosted runner или cron на своём сервере с коммитом результатов.
3. **РЭО без условных запросов.** 21 МБ раз в сутки. Разбираем потоково и берём только записи новее последней сохранённой.
4. **solidwaste.ru без года в дате.** Год берём из текущей даты запуска, а если получилась дата в будущем, то из прошлого года.
